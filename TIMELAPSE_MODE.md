# ТЗ для Клода: Разработка модуля автоматического таймлапса звездного неба

## Контекст проекта
У меня уже есть рабочее ПО с веб-интерфейсом для удаленного управления камерой Canon. Тебе необходимо разработать и интегрировать новый модуль автоматического и принудительного создания таймлапсов.

Интеграция с камерой должна происходить через наши существующие API-методы управления (или напрямую через вызовы gphoto2, если применимо — *прим. разработчика: Клод сам спросит детали*).

---

## 1. Режимы работы и логика запуска

Модуль должен поддерживать два режима, управляемых из веб-интерфейса:

### Режим 1: Принудительный («Просто таймлапс»)
* Запускается пользователем вручную одной кнопкой в веб-морде или по жесткому расписанию (cron).
* Игнорирует погодные условия и доступность звезд.
* Работает по заданному интервалу и количеству кадров (или до команды «Стоп»).

### Режим 2: Автоматический («Звездный таймлапс»)
Система каждую ночь (или по крону перед закатом) проверяет условия. Съемка начинается **только если звезды действительно видно**.

#### Определение доступности звезд (Логика для Авто-режима):
Реализуй интеграцию с бесплатным API погоды (например, Open-Meteo или OpenWeatherMap). Съемка разрешена, если одновременно выполняются условия:
1. **Облачность (Cloud Cover):** Меньше 15% (параметр `clouds` или `cloud_area_fraction`).
2. **Время суток:** Строго между астрономическими сумерками (после заката и до рассвета). Используй координаты локации.
3. **Опционально (Фаза луны):** Оценка засветки (информационно для отчета).

---

## 2. Пресеты экспозиции для Canon

Для автоматического режима система должна перед стартом отправлять на камеру Canon следующие настройки (через CLI-утилиту или API):

* **Пресет "Clear Night" (Основной):** Режим M (Manual), ISO 1600–3200, Выдержка (Shutter) 15–20 сек, Диафрагма (Aperture) максимально открытая (например, f/2.8). Фокус должен быть предварительно заблокирован на бесконечность.
* **Пресет "Moonlit Night" (Если луна > 50% освещена):** ISO 800, Выдержка 10–13 сек.
* **Для Принудительного режима:** Дай возможность пользователю выбрать пресет из веб-интерфейса или использовать текущие настройки камеры.

---

## 3. Автоматическое формирование фото и пайплайн

1. **Интервалометр:** Скрипт делает снимки с шагом `Выдержка + 5 секунд` (например, каждые 25 секунд при выдержке 20 сек), чтобы буфер камеры успевал освобождаться.
2. **Формат и сохранение:** Снимки сохраняются локально в директорию `/data/timelapses/raw_sequences/YYYYMMDD_custom_or_auto/` в формате JPEG (или RAW, если указано в настройках).
3. **Именование файлов:** Строго по порядку, например: `frame_00001.jpg`, `frame_00002.jpg`.

---

## 4. Обработка видео, Сборка мусора и Локальное хранение

1. **Склейка (FFmpeg):** По окончании сессии (наступил рассвет, закончился лимит кадров или нажата кнопка «Стоп») запускается фоновый процесс склейки через FFmpeg.
   * Команда для Клода: `ffmpeg -framerate 24 -i frame_%05d.jpg -c:v libx264 -pix_fmt yuv420p output.mp4`
2. **Сохранение:** Готовое видео сохраняется в `/data/timelapses/archive/YYYY/MM/video_YYYYMMDD.mp4`. В веб-интерфейсе должен появиться плеер для просмотра этого архива.
3. **Сборка мусора (Очистка):** После *успешной* склейки видео-ряда и валидации файла `.mp4`, исходная папка с тысячами JPEG-кадров должна быть автоматически удалена для экономии места на диске.

## 5. Email-уведомления и Ежедневный отчет

Система должна отправлять красивый HTML-отчет на указанный email.

### А) Оперативное уведомление (сразу после сборки)
* **Тема:** 🌌 Таймлапс готов: [Дата] (Авто / Принудительный)
* **Тело:** Короткая сводка и **Вложение (Attachment):** 3-5 превью-кадров (первый, средний, последний) в уменьшенном разрешении для быстрой оценки качества.

### Б) Ежедневный красивый отчет (раз в сутки утром)
Сделай адаптивную HTML-верстку в темных тонах (космическая тема). Отчет должен быть интересным и содержать:
1. **Статус:** "Успешно" / "Пропущено (Облачно)" / "Прервано пользователем".
2. **Метрики:** Количество снятых кадров, длительность получившегося видео, средняя облачность за ночь, объем освобожденного места на диске.
3. **Сводка погоды:** Какая была температура и фаза луны.
4. **Текстовая «Лирика ночи»:** Динамический текст, генерируемый по шаблону (например: *"Этой ночью небо над камерой было идеально чистым (облачность 4%). Камера Canon успешно отработала 4 часа на пресете Clear Night, поймав в кадр 576 звездных мгновений. Мусор успешно убран, диск чист!"*).
5. **Мини-галерея:** Встроенные в тело письма (через `Content-ID` / `cid`) 3 превью-снимка.
